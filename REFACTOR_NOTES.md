# NECTAR: исправления без редизайна

Исходный коммит: f20454ad6efa45a9b14d7b4ae1ec1b874c2c9eed.

Сохранены исходные семейства, размеры, насыщенность и цвета шрифтов, палитра, оформление карточек и фотография. Автоматическое сравнение computed styles с исходной версией совпало для логотипа, подписи, основных вкладок, категорий, заголовков, описаний, цен и веса.

## Исправления

- Один переход между кухней, баром и банкетом; очистка поискового состояния в любом режиме.
- Отменяемые отложенные действия: устаревшие callbacks поиска и навигации не перезаписывают последний переход.
- Мгновенные переходы больше не наследуют глобальную плавную прокрутку; первая категория выравнивается под закреплённой навигацией.
- Общий жизненный цикл обоих диалогов: блокировка фона, удержание фокуса, восстановление позиции, защита от повторного закрытия.
- Кэш уже созданных карточек по языку и режиму, отложенный рендер банкета, повторное использование форматтеров цен.
- Исправлен повреждённый фрагмент CSS с буквальными `\n`; шрифтовые и цветовые правила не изменены.
- Иконки заменены локальными SVG с ограниченными размерами. Подключение исходных Google Fonts сохранено.
- Подменю кухни/бара и банкета поддерживает вертикальное колесо мыши для горизонтальной прокрутки, перетаскивание мышью без случайного выбора категории и клавиши Left/Right/Home/End. Нативный свайп сохранён.

## Проверка

69/69 автоматических проверок прошли в Chromium: ширины 320, 390, 1280 px; RU, KZ, EN; переключения, гонка очистки поиска, обе модалки, фокус и прокрутка, горизонтальное переполнение, отсутствие JS-ошибок. Файлы menu-data.js и banquet-data.js побайтово не изменены относительно исходного коммита.

Локальный синтетический замер 30 последовательных переключений с измерением layout, без первых четырёх прогревочных измерений: медиана исходника 68,1 мс, исправленной версии 44,9 мс. Это не замер загрузки по мобильной сети и не гарантия производительности на устройствах гостей.

Проверка на физическом iPhone/Safari и Android и полевая оценка загрузки остаются необходимыми перед публикацией. В действующий сайт ничего не опубликовано.

Дополнительно прошли 8/8 целевых проверок прокрутки: колесо, перетаскивание без случайного выбора и End для обоих подменю, а также свайп через touch events в эмуляции Chromium. Это не проверка на физическом телефоне.

## Запуск

Распакуйте архив и запустите статический сервер из папки проекта, например `python -m http.server 8765`. Для QA: `npm install`, `npx playwright install chromium`, затем `npm test` при работающем сервере. URL можно задать переменной `BASE_URL`.
