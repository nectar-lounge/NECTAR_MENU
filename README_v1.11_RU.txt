NECTAR v1.11 — IA Menu Selector

База: v1.10 Stabilization (визуальный golden master).

Изменения только в информационной архитектуре:
- КУХНЯ / БАР / БАНКЕТЫ объединены в один верхний selector.
- Selector расположен до поиска, чтобы три сценария меню были видны сразу.
- БАНКЕТЫ открывают существующий banquet-section без дублирования контента.
- Нижняя навигация упрощена до МЕНЮ / ИНФО.
- Неудачные CTA/монограмма из экспериментальной v1.11 Discoverability не использованы.
- Карточки, цены, modal, unavailable-state, поиск, категории, hero и Info визуально не перерабатывались.
- Для экранов <360px добавлена только адаптация типографики selector, чтобы три подписи не ломали геометрию.
