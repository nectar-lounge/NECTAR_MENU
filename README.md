# NECTAR — электронное меню

Готовый статический сайт электронного меню NECTAR Lounge · Bar · Kitchen.

## Что внутри

- `index.html` — страница меню
- `styles.css` — дизайн
- `menu.js` — все блюда и цены
- `app.js` — логика поиска, разделов и карточек блюд

## Как добавлять выход и состав

Откройте `menu.js`. У каждого блюда есть:

```js
{
  id: "1-1",
  category: "Холодные закуски",
  name: "Мясное плато (казы, жая, жал)",
  price: 4990,
  weight: "",
  composition: "",
  note: ""
}
```

Позже достаточно заменить пустые значения:

```js
weight: "350 г",
composition: "казы, жая, жал, зелень",
note: ""
```

После сохранения сайт автоматически покажет их в карточке блюда.

## Бесплатное размещение

Рекомендуемый вариант — GitHub Pages.

1. Создать бесплатный аккаунт GitHub.
2. Создать публичный репозиторий, например `nectar-menu`.
3. Загрузить все файлы из этой папки в корень репозитория.
4. В Settings → Pages выбрать публикацию из ветки `main`, папка `/root`.
5. GitHub выдаст постоянный адрес вида:
   `https://ВАШ-АККАУНТ.github.io/nectar-menu/`

Именно этот адрес потом используется для статического QR-кода.

## Важно

Не используйте сторонний QR-редирект. QR должен вести непосредственно на адрес GitHub Pages. Тогда нет подписки, рекламы и зависимости от QR-сервиса.

## Что нужно заменить перед запуском

В `app.js` заполнить:

```js
const LINKS = {
  telegram: "ссылка на Telegram",
  map: "ссылка на карту",
  phone: "ссылка tel:"
};
```

Если пока оставить `#`, кнопки будут неактивны.

## Номер стола

Структура уже рассчитана на дальнейшее добавление номера стола через QR-параметр, например:

`?table=7`

Это позволит в будущем сделать QR для каждого стола и автоматически показывать гостю:
`Вы за столом №7`.
