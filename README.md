# NECTAR — Электронное QR-меню

**Lounge · Bar · Kitchen**  
Алматы, Казахстан

---

## Описание

Статический сайт-меню для заведения NECTAR.  
Поддерживает три языка: русский, казахский, английский.  
Сохраняет выбранный язык в localStorage.

---

## Структура

- Главный экран с приветствием и выбором языка
- Меню (блюда из DOC-файла)
- Напитки (вино, водка, пиво, безалкогольные)
- О NECTAR (заглушка)
- Информация для гостей (заглушка)
- Контакты (телефон, 2GIS)

---

## Технологии

- HTML + CSS + JavaScript
- Никаких внешних библиотек
- SVG для графики
- Адаптировано под мобильные устройства
- Работает на GitHub Pages

---

## Как загрузить в GitHub

1. Распакуйте архив
2. Перейдите в репозиторий `hormigon-143/NECTAR_MENU`
3. Загрузите все файлы в корень репозитория
4. GitHub Pages автоматически опубликует сайт по адресу:  
   https://nectart-lounge.github.io/NECTAR_MENU/
