NECTAR MENU v1.9.2 — OPTICAL PRICE NUMERALS

Точечный патч поверх v1.9.1.

Что изменено:
- Цена больше не использует Manrope для цифровой строки.
- Для цифр цены используется системная UI-гарнитура устройства
  (SF Pro / Segoe UI / Roboto / Helvetica / Arial fallback).
- Это не добавляет новых сетевых шрифтов и не замедляет загрузку.
- Убрано отрицательное межбуквенное расстояние у цены.
- Сохранены lining-nums + tabular-nums.
- Одинаковая numeric-система применяется к карточке и modal.
- Знак ₸ остаётся меньше суммы и выровнен по baseline.

Визуальная концепция, размеры карточек, modal, меню и данные не менялись.
